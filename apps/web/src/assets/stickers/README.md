# Stickers

Starter illustrations in the flat-sticker style: 4px ink outlines, sticker-palette fills, and a solid ink shadow offset 8px down-right (twice `shadow-md`, because illustrations sit at hero scale). 160×120 viewBox each.

- `sealed-envelope.svg` — highlight envelope with a coral wax seal. Hero, "Sealed" empty states, the Set beat in judge mode.
- `key.svg` — pink key. Release flow, ReleaseMeter empty state.
- `key-ring.svg` — a paper key ring with two keys hanging from it (pink and lavender, the `key.svg` shape). The landing page's "2-of-3 release / Two keys to open" tile. Its keys are drawn at 0.58 scale, so its shadow offset is scaled with them (5 instead of 8) to keep the same proportion as `key.svg`.
- `padlock.svg` — teal padlock. Security page, epoch and revoke explanations.
- `authentic-stamp.svg` — mint stamp with a check. The Authentic moment when an invigilator opens a paper.
- `canary.svg` — highlight canary. Leak detection ("canary copies"), the Leak beat.

Rules: fixed hex fills (they are images, not icons), never recolored per theme. One sticker per card or empty state; on the landing page they may bleed off a tile's edge and tilt up to ±12°. Never put text on a sticker. New stickers follow the same recipe and use only sticker-palette fills plus `ink` and `surface-page` paper.
